## ✨ Interactive Features

- **Smooth Folio Navigation:** Keyboard arrows (`←` and `→`), navigation buttons, or instant Table of Contents drawer for jumping to any of the 15 folios.
- **Micro-Simulation Engines:** 15 distinct interactive mechanical widgets demonstrating each invention's physical operation.
- **Acoustic Design (Web Audio API):** Organic dry parchment page flips, gear clicks, telegraph beeps, and baroque harmonies.
- **Optical Magnifying Loupe:** Brass reading glass moving across the illuminated folios.
